# الخدمات الخارجية

- Firebase Authentication وFirestore وHosting وFCM خدمات خارج ملفات المصدر. الحسابات وقاعدة البيانات وحالة النشر الحالية لم تُنسخ أو تُفحص في عملية التنظيم.
- المصدر يتضمن وظائف الإشعارات. الوثائق القديمة تشير إلى أن نشرها توقف بسبب شرط خطة Blaze؛ هذه معلومة سابقة لم يُتحقق من استمرارها الآن.
- رفع الصور وملفات PDF يعتمد على خدمة خارجية يحدد عنوانها schoolConfig/media.uploadBaseUrl. كود تلك الخدمة وأسرارها غير موجودين في المجلد الأصلي.
- Google OAuth وشهادات توقيع Android يجهزها المالك. إعدادات Firebase العميل الموجودة ليست حساب خدمة إداري.
- مسار وتلميذ تيس خدمات خارجية يفتحها التطبيق عبر Android System WebView.
- يعاد تنزيل Android SDK وJDK وGradle وتبعيات Maven وnpm حسب ملفات إعداد المشروع.

موقع الإدارة تطبيق ويب؛ لم يوجد مثبت مستقل بصيغة EXE أو MSI في المشروع. ملف app-beta09.apk الموجود في مخرجات debug حُفظ منفصلاً دون إعادة بناء أو تغيير.
